# 💍 Samju M.C & Fahiza K.K — Luxury Wedding Invitation Website

A luxury, animated, and responsive wedding invitation website designed for **Samju M.C** and **Fahiza K.K**, celebrating their wedding on **January 17, 2027** at the **Nalanda Convention Centre, Calicut, Kerala**.

Crafted with **React.js**, **Tailwind CSS**, and **Framer Motion**, following a **Deep Burgundy, Dark Maroon, and Metallic Gold** visual identity inspired by the couple's official wedding invitation card.

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start the development server (runs on http://localhost:5173/)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
